# Font source

Lilita One Regular was downloaded from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/lilitaone
- Font: https://raw.githubusercontent.com/google/fonts/main/ofl/lilitaone/LilitaOne-Regular.ttf
- License: https://raw.githubusercontent.com/google/fonts/main/ofl/lilitaone/OFL.txt

The original TTF and its SIL Open Font License are included unchanged. Unity TextMeshPro generates the dynamic SDF font asset and shared UI materials from this source. Character names, values, and labels remain editable text.
