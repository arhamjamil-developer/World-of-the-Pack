# Card UI exact generation prompts

Built-in image generation was used for all source art. The approved roster and integrated gameplay mockup were the visual references. Original source atlases are preserved under `Sources`; `Prepare-CardArt.ps1` mechanically crops and packs separate PNGs. Names, numbers, and control labels are added as editable TextMeshPro components in Unity.
