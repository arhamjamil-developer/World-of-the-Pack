# Environment path exploration

Recommended starting environment: **Sunny Forest Trail**. The warm path contrasts with the colorful characters, while trees and props frame an uncluttered combat space.

Use **Mushroom Grove** as the first visual variation, with the same path width, camera, and combat rules. Use **River Crossing** later as a landmark encounter. The illustrated bridge is narrower than the clearings: widen it to the full intended squad formation width in the playable layout, or define and test an explicit bottleneck mechanic before using that narrowing.

Allies enter from below and face north; enemies approach from above. Blue and orange arrows/circles on this board are layout annotations, not proposed permanent floor graphics.

Keep center-floor detail low contrast. Concentrate trees, flowers, rocks, mushrooms, fences, and motion near the outer margins. Avoid canopies obscuring actors or large VFX competing with attack warnings.

For iPhone portrait, preserve a clear battle corridor above the bottom cards. For iPad portrait, reveal more scenery at the sides while maintaining character size and the same playable corridor. Additional screen width should not silently change spawn density, attack ranges, or difficulty.

This is a visual exploration board, not a tileable background, sliced environment pack, collision map, or implemented scene. Build separate ground, edge-prop, foreground, and effect layers when producing the actual environment assets.

Generation method: built-in image generation. Exact prompt is saved as `environment-path-comparison-v01-prompt.txt`.
